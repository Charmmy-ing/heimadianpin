# 【Java｜Spring Boot】黑马点评 - 本地生活服务平台实战

Spring Boot + Redis 做的本地生活点评平台，跟着课程完成核心业务模块。

## 功能模块
- 商铺管理、商铺类型查询
- 优惠券管理与秒杀下单
- 用户登录鉴权、关注与博客社区互动
- 图片上传
